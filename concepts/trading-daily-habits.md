# Trading Daily Habits

## Pattern Recognition Practice

- Study **300 examples** of each setup type
- **Print them out** for multiple reviews
- Embed patterns into **subconscious memory**

## Entry Rules

- **9:33-9:35 entry time** — stock must close near high
- Never buy fading price action
- Short only in **last 15 minutes** to minimize overnight risk

## Leg Management

- Focus on **first and second leg** moves
- Avoid third and fourth leg opportunities
- Third leg positions: **watch like a hawk with very tight stops**

## Setup Confusion Prevention

- Create **personal playbook** with setup examples
- Eliminates confusion between different pattern types
- Each setup has distinct characteristics — visual reference prevents errors

## Filter Discipline

- **Question every indicator** and filter requirement
- Understand if it truly adds value or eliminates opportunities
- Ignore inherited assumptions that don't add edge

## Daily Scan Review

- Review daily scan results
- Identify which stocks showed **continuation setups**
- Builds **pattern reinforcement training**

## Market Breadth Awareness

- Check breadth before **continuation long** entries
- Weak structure shorts work regardless of breadth

## Volatility Check

- **Buy only when volatility decreases** during consolidation
- Shows orderly rather than chaotic profit taking

## Setup Qualification

- Watch for **linearity** during first leg as primary qualification criterion
- Wait for **3-10 day consolidation**, not just one day pause

## Short Setup Specifics

- Enter short **only after confirming** each bounce day is < 2.5%
- During weak consolidation

## Feedback Loop

- Track which setups worked and failed
- Refine visual pattern recognition through **deliberate feedback**
- Review → Learn → Adjust
