**Hub für Josts Trading-Wissen. Saubere Dreiteilung: Philosophie → Prozess → Setups.**

## Die drei Ebenen

```
┌─────────────────────────────────────────────────────────────┐
│                  TRADING BRAIN                                │
├─────────────────┬─────────────────────┬─────────────────────┤
│  EBENE 1        │  EBENE 2             │  EBENE 3             │
│  PHILOSOPHY     │  PROZESS             │  SETUPS              │
├─────────────────┼─────────────────────┼─────────────────────┤
│  Mindset        │  Morning Routine     │  EP9M                │
│  Marktverst.    │  NTRT/MTRT Scans     │  DEP                 │
│  Prinzipien    │  Entry-Taktiken       │  FHP                 │
│                 │  Position Sizing      │  SOS                 │
│                 │  Exit Rules          │  Story Trading       │
│                 │  Report Card         │  Sugar Babies (EP9M)│
└─────────────────┴─────────────────────┴─────────────────────┘
```

**FEE** = Entry-Taktik (in Ebene 2), kein eigenständiger Setup.

## Warum diese Struktur?

| Ebene | Frage | Antwort |
|-------|-------|---------|
| **Philosophy** | *Was glaube ich über den Markt?* | Kein Trade ohne klares Mindset |
| **Prozess** | *Wie treffe ich Entscheidungen?* | Systematisch, nicht emotional |
| **Setups** | *Was trade ich konkret?* | Regeln statt Ratens |

Jede Ebene informiert die andere. Philosophy ohne Prozess = Handlungsunfähig. Prozess ohne Setups = kein Edge. Setups ohne Philosophie = undiszipliniertes Ratieren.
